# 🚀 Yukti Payak | MERN Stack Developer Portfolio

A modern, responsive, and performance-optimized **developer portfolio website** built using **Next.js** and enhanced with **ReactBits** animations. The site showcases projects, skills, and achievements while providing a fully functional **contact form powered by Nodemailer** for direct email communication.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React & React Icons
- **Backend**: Next.js API Routes 
- **Email Service**: Nodemailer 
- **Animations**: ReactBits

## ✨ Key Features

-  **Fast & SEO-Friendly** – Built with Next.js for optimized performance
-  **Interactive Animations** – Smooth UI effects using ReactBits
-  **Fully Responsive** – Works seamlessly across all devices
- **Contact Form Integration** – Secure email handling via Nodemailer
-  **Component-Based Architecture** – Clean, reusable React components
-  **Scalable Structure** – Easy to extend with new sections and features
